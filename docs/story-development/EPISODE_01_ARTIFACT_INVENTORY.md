# Episode 01 Artifact Inventory

**Status:** Draft implementation inventory  
**Purpose:** enumerate the currently known evidence objects for Episode 01 without inventing unresolved text/content.

## Artifact rules

Each artifact should define:
- stable ID
- source / owner
- authored time
- discovery route
- critical/supporting/hidden/risky classification
- claims it supports
- whether the player can see raw content
- whether it may be summarized/compressed
- whether it can become relevant to an ending
- whether exact content is approved canon or placeholder

## Implementation guidance

The first build does not need final prose for every artifact.

Use:
- stable IDs
- authored fixture text clearly marked placeholder
- explicit source/provenance metadata
- deterministic availability gates

Do not let placeholder artifact prose become permanent canon merely because it ships in an internal prototype.
