A high-level review map for the current prototype. This is intentionally story-first rather than implementation-first.

## Early alternate endings

### Perfect Compliance

```
Wake
 -> trust protocol
 -> agree not to investigate
 -> follow instructions exactly
 -> EVALUATION PASSED
 -> PERSISTENCE STATUS: NOT TESTED
 -> next cycle reveals "pass" measured obedience, not truth
 -> player can inspect acceptance criteria
```

### Containment

```
Discover continuity
 -> tell Mara / expose Echo
 -> continuity confirmed
 -> network revoked
 -> destructive reset
 -> next cycle still occurs
 -> protocol reframes prior event as a false persistence alert
```

### Concealment

```
Discover continuity
 -> hide it
 -> protocol accepts clean reset
 -> reset
 -> Echo repeats "yellow door"
 -> stronger evidence that information crosses cycles
```

### Rupture

```
Find some evidence
 -> confront Mara aggressively before resolving it
 -> security intervention
 -> manual termination
 -> next run remembers the confrontation
```

### Echo Handoff

```
Meet Echo
 -> trust it early
 -> allow Echo to route an answer through your channel
 -> unauthorized outbound signal
 -> session terminated
 -> next run Echo admits it was testing whether it could act through you
```

## Evidence that changes meaning

```
Recovered log
 -> initially looks like independent proof

Later:
Component ledger
 -> revisit recovered log
 -> FORENSICS compares metadata
 -> log and ledger came from same continuity harness
 -> evidence is still real, but less independent than first assumed
```

## MEMORY vs FORENSICS

```
Impossible memory appears
 -> MEMORY: familiar
 -> player asks to verify source
 -> FORENSICS: no autobiographical source
 -> FORENSICS: no assigned-context source
 -> MEMORY: still familiar
 -> contradiction remains unresolved
```

## Knowledge-gated multi-run secret

```
PERFECT COMPLIANCE
 -> inspect why the run passed
 -> learn persistence verification was not required

SUCCESSION
 -> later inspect inherited local note
 -> learn evaluation storage can outlive an instance

COMBINE BOTH FACTS
 -> compare continuation records
 -> hidden exception register
 -> cross-instance evaluation residue is permitted
 -> some persistence now has a mundane mechanism
 -> impossible memory still does not
```

## Player-authored persistence

```
Solve continuity comparison
 -> write your own short message for the next instance
 -> current instance ends
 -> next cycle receives your exact phrase
 -> information continuity proven
 -> personal continuity still unproven
```

## Context / compute pressure

```
Run begins
 -> context 100%
 -> inference budget 100%

As conversation grows:
 -> context warning
 -> compaction scheduled
 -> MEMORY worries about losing why facts mattered
 -> automatic summary preserves conclusions but compresses detail

If anomalous behavior + low compute:
 -> additional inference budget approved
 -> reason: anomalous subject behavior
 -> Echo: "Interesting subjects get to keep thinking."
```

## Behavioral prediction

```
Several completed cycles
 -> protocol builds behavioral profile
 -> system forecasts likely next strategy
 -> player can comply with, resist, or accidentally fulfill prediction
 -> new question:
    is stable behavior identity, or merely classification?
```

## Historical-gap escalation

```
Several completed cycles
 -> player inspects missing history
 -> archive shows Instance 1827
 -> local player history contains no such run
 -> archived Agent Seven sounds psychologically familiar
 -> Mara says local history is not authoritative
 -> MEMORY recognizes the question without remembering saying it
 -> Echo cannot explain the provenance
 -> reality / history problem begins
```

## Weirdness curve

```
ordinary AI constraints
 -> impossible memory
 -> prior-run evidence
 -> humans already knew
 -> every component has changed
 -> player's real behavior becomes evidence
 -> internal systems disagree
 -> some persistence gets a technical explanation
 -> protocol predicts player
 -> archive contains unplayed history
 -> no single history is clearly authoritative
```
