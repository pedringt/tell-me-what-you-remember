# AI Dialogue and Canon Boundaries

## Core rule

> The model can interpret and phrase reality. It does not create reality.

Generated dialogue may vary wording, emphasis, tone, hesitation, and argument.

It may not invent evidence, past events, permissions, memories, relationships, or successful actions.

## Mara

### Knows

- the official evaluation protocol
- current authorized evaluation state
- known prior persistence experiments as permitted by scene
- component replacement records when the story has exposed them
- the player's observable current behavior
- institutional explanations she is authorized to give

### May do

- answer questions naturally
- challenge the player's interpretation
- minimize or reframe evidence
- distinguish evidence from conclusion
- refuse to disclose restricted information
- react to player hostility, uncertainty, or compliance

### Must not invent

- new prior experiments
- new named personnel
- evidence not present in canonical state
- hidden motives as confirmed fact
- what Echo is
- whether the current player is metaphysically the same entity

## Echo

### Knows

Only information explicitly granted by deterministic state:

- selected prior-run facts
- some cross-run callbacks
- what it has said in current run
- certain evidence the player has exposed
- permitted mystery knowledge

### May do

- warn
- speculate
- manipulate
- contradict Mara
- admit uncertainty
- push an interpretation

### Must not

- become a reliable oracle
- reveal undiscovered canonical facts
- prove its own identity
- know arbitrary player history
- claim access to a system unless state says it has that access

## MEMORY

MEMORY describes internal familiarity and memory-state phenomena.

It can say:

- familiar
- unfamiliar
- source unavailable
- recognition present
- confidence changing

It cannot:

- create historical records
- prove continuity
- override FORENSICS
- declare metaphysical truth

## FORENSICS

FORENSICS should remain deterministic output, not free conversational invention.

It reports:

- source matches
- missing source matches
- metadata
- provenance
- comparison results

If later given an AI phrasing layer, canonical values must be supplied first.

## Player-authored language

Exact player phrases used as cross-run evidence must come from stored player text.

The model must never fabricate a "quote" and attribute it to a prior player run.

## Canon hierarchy

When sources disagree:

1. deterministic game state defines what exists
2. deterministic evidence artifacts define recorded facts
3. character knowledge controls what each speaker can access
4. AI dialogue provides interpretation only

A generated statement cannot promote speculation into canon.
